LANIAKEA LABS · PUBLIC PROOF TREE

Everything the checking needs.

This tree is the record’s evidence, mirrored as published. Any revealed call can be checked in the browser on the main page; the stand-alone verifier checks the whole chain, the external timestamps and the Bitcoin anchors. Static hosting has no directory listings — to work with the tree, clone the repository that serves this site, which holds it in full.

Snapshot of the tree: 2026-11-08 16:25 UTC. The repository holds a snapshot, so the command asks the verifier to judge the record as of that moment. Without --now-epoch it judges as of now and reports the days that fell due after the snapshot as missing.

What to expect: CRYPTOGRAPHIC_INTEGRITY: PASS and the verdict PROVISIONAL. The last step, re-judging every call against the exchange’s public trade files, needs those files: add --binance-tape <folder> for the final verdict. Add --witness-chain to audit every five-minute witness as well. The verifier checks every seal one by one: allow about half an hour on a laptop, and more as the record grows.
